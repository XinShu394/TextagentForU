# 云服务器安装清单

> **目标环境**：阿里云 ECS（Ubuntu 22.04+ / Debian 12+）
> **运行标准**：一切以云服务器上稳定运行为准
> **使用方式**：架构修改完成后，按此清单统一安装

## 一、系统级依赖（apt）

| 包名 | 用途 | 优先级 |
|------|------|--------|
| `python3` | Python 运行环境（3.9+） | 🔴 必装 |
| `python3-pip` | Python 包管理器 | 🔴 必装 |

| `nginx` | 反向代理（80/443 → 9000） | 🔴 必装 |
| `curl` | cron 触发脚本（trigger.sh）调用 /system 端点 | 🔴 必装 |
| `cron` | ECS crontab 定时调度（替代 APScheduler） | 🔴 必装 |
| `ufw` | 防火墙管理（22/80/443） | 🟡 推荐 |
| `certbot` | Let's Encrypt SSL 证书自动续期 | 🟡 推荐 |
| `python3-certbot-nginx` | certbot Nginx 插件 | 🟡 推荐 |
| `logrotate` | 日志自动轮转（通常系统自带） | 🟡 推荐 |

**一键安装命令**：
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git nginx curl cron ufw
# 可选：SSL 证书
sudo apt install -y certbot python3-certbot-nginx
```

## 三、系统配置

### 3.1 Swap 虚拟内存（小内存 ECS 必做）

```bash
# 检查是否已有 swap
free -h

# 创建 2GB swap
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### 3.2 防火墙（ufw）

```bash
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP（Nginx）
sudo ufw allow 443/tcp   # HTTPS（SSL）
sudo ufw --force enable
sudo ufw status
```

> ⚠️ 同时需要在阿里云安全组中放行 80 和 443 端口

### 3.3 时区设置

```bash
# crontab 依赖正确的时区！
sudo timedatectl set-timezone Asia/Shanghai
timedatectl    # 验证
```

## 四、Nginx 反向代理配置

```bash
# 删除默认配置
sudo rm -f /etc/nginx/sites-enabled/default

# 写入 TextAgent 配置
sudo tee /etc/nginx/sites-available/textagent << 'EOF'
server {
    listen 80;
    server_name textagent.cn www.textagent.cn;

    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options DENY;

    location / {
        proxy_pass http://127.0.0.1:9000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300;
        proxy_connect_timeout 60;
        proxy_send_timeout 300;
        client_max_body_size 50m;
    }
}
EOF

# 启用配置
sudo ln -sf /etc/nginx/sites-available/textagent /etc/nginx/sites-enabled/textagent
sudo nginx -t && sudo systemctl restart nginx && sudo systemctl enable nginx
```

## 五、Crontab 定时调度配置

```bash
# 1. 复制触发脚本到固定路径
sudo mkdir -p /opt/textagent
sudo cp deploy/crontab/trigger.sh /opt/textagent/trigger.sh
sudo chmod +x /opt/textagent/trigger.sh

# 2. 安装 crontab（当前用户）
crontab deploy/crontab/textagent.cron

# 3. 验证
crontab -l
```

**7 个 cron 任务一览**：
| 任务 | 调度 | 说明 |
|------|------|------|
| `todo_remind_tick` | 每 1 分钟 | 待办提醒心跳 |
| `scheduler_tick` | 每 30 分钟 | 智能调度心跳 |
| `refresh_cache` | 每 30 分钟 | 缓存刷新 |
| `daily_init` | 每天 05:00 | 生成当天意图队列 |
| `weekly_review` | 每周一 09:00 | 周回顾 |
| `monthly_review` | 每月 1 号 09:00 | 月度回顾 |
| `finance_monthly_report` | 每月 8 号 20:00 | 财务月报 |

## 六、systemd 服务配置（开机自启）

```bash
sudo tee /etc/systemd/system/textagent.service << 'EOF'
[Unit]
Description=TextAgent AI Assistant
After=network.target nginx.service
Wants=nginx.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/TextAgentForU/src
ExecStart=/usr/bin/python3 /root/TextAgentForU/src/app.py
Restart=always
RestartSec=10
StandardOutput=append:/root/textagent_stdout.txt
StandardError=append:/root/textagent_stderr.txt
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable textagent
sudo systemctl start textagent
```

> 📝 如果使用了 venv，需要把 `ExecStart` 改为：
> ```
> ExecStart=/root/TextAgentForU/venv/bin/python3 /root/TextAgentForU/src/app.py
> ```

## 九、日志轮转配置（防止日志撑爆磁盘）

```bash
sudo tee /etc/logrotate.d/textagent << 'EOF'
/var/log/textagent_cron.log
/root/textagent_stdout.txt
/root/textagent_stderr.txt {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    copytruncate
}
EOF
```

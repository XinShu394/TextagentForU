# 管家人格改造：从工具到管家

**日期**：2026-03-30  
**版本**：V0.3 人格升级  
**触发原因**：用户反馈 TextAgent 交互太"工具化"——说"你好"回复"已记录到 Obsidian"，缺乏温度和陪伴感

---

## 问题分析

### 根因
1. **SOUL 人格定位**：原定位为"个人 AI 助手"，缺乏管家/陪伴角色认知
2. **Flash 快速回复路径**：短消息（<50字）走 Flash 模型，提示词偏向工具分发，简单问候被错误路由到 `note.save`
3. **LLM 失败兜底**：当 LLM 返回空或 JSON 解析失败时，直接回复"已记录到 Obsidian"——冷冰冰
4. **兜底回复逻辑**：无回复时 fallback 为"记住啦~"/"已记录 ✅"/"收到~"/"好的~"——全是工具语气
5. **欢迎与功能介绍**：使用"AI 生活助手 🤖"自称——机械感强

---

## 设计原则

1. **聊天优先**：问候、闲聊、情绪表达 → 走 `chat` skill 直接回复，不存笔记
2. **温度优先**：所有系统回复使用口语化、有情感的表达
3. **禁止"已记录到 Obsidian"**：任何路径都不再输出此类冷冰冰回复
4. **管家角色感**：自称"小管家"，关心主人日常，时段感知（早安/晚安）
5. **适度热情**：不谄媚、不过度，像一个靠谱的老朋友

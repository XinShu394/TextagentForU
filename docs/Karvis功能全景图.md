## 一、新用户引导流程（Onboarding）

### 触发方式

首次使用自动触发，共 4 步引导。

### 步骤流程

**Step 1：设置昵称**

- AI 问："你希望我怎么称呼你？"
- 用户：说"叫我小天" → 提取昵称
- 反馈：短确认，进入 step 2

**Step 2：给 AI 起名**

- AI 问："那你想给我起个什么名字呢？"
- 用户：说"叫你健健" → 保存 AI 名字
- 反馈：确认名字，引导试用功能

**Step 3：第一条笔记**

- 用户：随便发一句话（如"今天天气真好"）
- 系统：自动保存到速记 + 引导待办功能

**Step 4：第一个待办**

- 用户：说"添加待办 明天买咖啡"
- 系统：完成引导，生成 Web 查看链接

## 二、核心记录功能

### 1. 速记（Quick Notes）

**触发方式**：所有用户消息自动保存（无需指令）

**记录范围**：

- 生活感受、心情、见闻
- 碎碎念、吐槽、分享
- 图片/语音/视频消息

**反馈形式**：

- 一般情况：无声保存（不打扰）
- 有记忆更新时：简短确认"记住啦~"

---

### 2. 分类归档（Classify Archive）

**触发方式**：AI 自动判断是否需要归档

**分类规则**：

| 类别 | 触发场景 | 示例 |
|------|---------|------|
| **work** | 工作记录、会议、技术笔记 | "今天开会讨论了新项目..." |
| **emotion** | 情感倾诉、感情相关 | "和小明吵架了，很难受..." |
| **fun** | 生活趣事、搞笑经历 | "刚看到猫在打自己尾巴哈哈" |
| **misc** | 无法归类的碎碎念 | "今天路过奶茶店..." |

**反馈形式**：简短确认，如"收到，已归档到工作笔记~"

---

### 3. 读书笔记

**触发方式**：提到书名时自动识别

| 操作 | 触发词 | 参数 | 反馈 |
|------|--------|------|------|
| **创建/切换** | "最近在看《三体》" | 书名、作者、分类 | "好，帮你创建了《三体》笔记~" |
| **添加书摘** | "书中写到：..." | 原文内容 | "已保存到《三体》摘录~" |
| **记录感想** | "看到这里感觉很震撼..." | 感想内容 | "收到，感想已记录~" |
| **生成总结** | "总结一下三体" | 书名（可选） | 长任务：先发"正在阅读笔记..."，再发总结报告 |
| **提炼金句** | "三体有哪些金句" | 书名（可选） | 长任务：返回 3-5 条适合分享的金句 |

---

### 4. 影视笔记

**触发方式**：提到影视作品时自动识别

| 操作 | 触发词 | 参数 | 反馈 |
|------|--------|------|------|
| **创建/切换** | "在追《繁花》" | 名称、导演、类型、年份 | "好，帮你创建了《繁花》笔记~" |
| **记录感想** | "这一集太精彩了..." | 感想内容 | "收到，感想已记录~" |

---

### 5. 语音日记（长语音自动整理）

**触发方式**：发送 30 秒以上的长语音（>200 字）

**处理逻辑**：

- ASR 识别 → 清洗整理 → 结构化分析
- 提取：主题、情绪轨迹、关键事件、人物、洞察

**反馈形式**：

```
✨ 已整理为语音日记：
主题：关于工作的焦虑与释然
情绪：焦虑 → 释然 → 平静
关键事件：...
```

## 三、待办管理

### 1. 添加待办（todo.add）

**触发方式**：识别任务意图

**触发词汇表**：

| 类型 | 触发词 | 示例 |
|------|--------|------|
| 明确提醒 | 提醒我、记得、明天要、todo | "明天提醒我买猫粮" |
| 行动意图 | 今天要、要搞、得做、打算做 | "今天要去超市" |
| 需求建议 | 需要加、要加个、还得 | "需要加个新功能" |

**时间解析**：

- **一次性提醒**（默认）：
  - "下午提醒我买猫粮" → `remind_at="2026-03-11 15:00"`（不填 recur）
  - "明天早上提醒我开会" → `remind_at="2026-03-12 09:00"`

- **循环提醒**（用户明确说"每天/每周/工作日"）：
  - "每天下午2点提醒我吃药" → `recur="daily"`, `remind_at="14:00"`
  - "工作日提醒我收拾桌子" → `recur="weekday"`
  - "每周一三五提醒我跑步" → `recur="weekly"`, `recur_spec={weekdays:[1,3,5]}`

**反馈形式**：

```
✅ 已添加：明天买猫粮
⏰ 提醒时间：明天 15:00
```

---

### 2. 完成待办（todo.done）

**触发方式**：

| 方式 | 触发词 | 示例 |
|------|--------|------|
| 关键词匹配 | "做完了、搞定了" + 内容 | "猫粮搞定了" |
| 序号引用 | 序号 + "完成了" | "2-7 完成了"、"第3个做完了" |

**反馈形式**：

```
✅ 已完成：买猫粮、写报告（共 2 项）
```

---

### 3. 查看待办（todo.list）

**触发词**：待办、有什么要做的、todo list

**反馈形式**：

```
📋 待办清单（3 项）：
1. 买猫粮 | 今天 15:00
2. 写周报 | 周五截止
3. 打电话给小明 | 无截止日
```

---

### 4. 取消提醒（todo.remind_cancel）

**触发词**：取消XX提醒、不用提醒了、停掉提醒

**反馈形式**：

```
✅ 已取消「吃药」的循环提醒
```

## 四、自动生成功能

### 1. 日报（Daily Report）

**触发方式**：

- 定时触发：每晚 22:30 自动生成
- 手动触发：用户说"今天的日报"

**生成内容**：

- 今日总结（2-3 句温暖总结）
- 情绪评分（1-10 分 + emoji）
- 亮点事件
- 标签提取
- 洞察/建议

**反馈形式**：

```
📝 2026-03-11 日报

今天整体状态不错，工作推进顺利，晚上和朋友聊天很开心 🌤️

情绪评分：7/10
亮点：完成了新功能开发、和小明聊了很久
标签：#工作 #友情 #平静

💡 洞察：最近工作状态稳定，适合保持节奏~
```

---

### 2. 情绪日记（Mood Diary）

**触发方式**：

- 定时触发：每晚 22:00 自动生成
- 手动触发：用户说"今天的情绪日记"

**生成内容**：

- 情绪走势（早上平静 → 下午开心 → 晚上自责）
- 关键时刻（最多 6 个情绪波动点）
- 情绪洞察

**反馈形式**：

```
💭 今日情绪日记

情绪曲线：早上平静 → 下午开心 → 晚上自责
综合评分：6/10 | 复杂但温暖 🌤️

关键时刻：
08:06 💭 担心项目进度 | 焦虑
14:30 😊 和同事吃饭很开心 | 愉悦
22:50 😓 又熬夜了有点自责 | 懊恼

💡 洞察：今天情绪起伏较大，或许需要更多休息...
```

---

### 3. 周回顾（Weekly Review）

**触发方式**：

- 定时触发：每周日 21:30 自动生成
- 手动触发：用户说"本周回顾"

**生成内容**：

- 情绪趋势图（7 天评分曲线）
- 碎片连线（2-4 个跨天关联发现）
- 数据统计（消息数、分类分布、高频人名、关键词）
- 核心洞察
- 下周建议

**反馈形式**：

```
📅 2026-03 第二周回顾

━━━━━━━━━━━━━━━━
情绪曲线：
03-05 平静 7 ━━━●━━
03-06 低落 5 ━━●━━━
03-07 平静 7 ━━━●━━
03-08 愉悦 8 ━━━━●━
...
平均分：7.1/10

━━━━━━━━━━━━━━━━
碎片连线：

🔗 工作压力与睡眠质量
周二加班后连续两天失眠，周四提前下班睡眠质量明显改善 — 工作强度直接影响休息。

🔗 朋友聚会后的充电效应

- 消息总数：23 条

- 提及最多：小明（3次）、项目（5次）
- 关键词：焦虑、开心、累

━━━━━━━━━━━━━━━━
💡 核心洞察：
本周情绪整体稳定偏积极，但工作强度波动大。社交互动对你来说是重要的充电方式。

下周建议：
1. 控制加班频率，保障睡眠质量
2. 保持每周 1-2 次朋友聚会
```

### 4. 月度回顾（Monthly Review）

**触发方式**：手动触发"本月回顾"

**生成内容**：

- 情绪日历（整月评分分布）

## 五、智能陪伴功能

### 1. 晚间打卡（Checkin）

**触发方式**：

- 定时触发：每晚 21:00 推送引导
- 用户主动：说"开始打卡"

**流程**：

```
【AI 主动推送】
今天完成了 2/3 待办，不错哦~
今天想复盘一下吗？

【用户回复"好"】
→ Q1: 今天有什么值得记录的时刻吗？
【用户回答后】
→ Q2: 给今天打个分吧（1-10）
【用户打分后】
→ 根据评分温暖回应，结束打卡
```

**跳过/取消**：

- "跳过" → 跳过当前问题
- "取消打卡" → 直接结束

**反馈形式**：温柔对话式引导，不生硬

---

### 2. 深度自问（Reflect）

**触发方式**：

- 定时触发：每晚 20:30 推送一个深度问题
- 用户主动：说"来个深度自问"

**问题类型**：引导自我探索的开放式问题

**流程**：

```
【AI 推送问题】
💭 今晚的深度自问：
"什么时候你会觉得自己是自由的？"

【用户回答】
→ AI 给出温柔有洞察力的回应（1-3 句）

【用户说"跳过"】
→ 下次再聊~
```

**查看历史**：

- 触发词："最近的深度自问"、"回顾自问"
- 反馈：展示最近 7 天的问答记录

---

### 3. 早报推送（Morning Report）

**触发方式**：每天 8:00 自动推送

**内容结构**：

```
☀️ 早安！

📋 今日待办（3 项）：
- 买猫粮 | 15:00
- 写周报 | 今天截止
- 打电话给小明

📖 《三体》已读 3 天，保持节奏~

💡 今天最重要的 3 件事是什么？直接告诉我~

📅 时间胶囊：
一个月前的你："准备 AI 日记新项目，很兴奋有意思"
—— 看，你真的做出来了呢！

🌤️ 今天 22 度，适合出去走走~
```

**智能适配**：

- 有在读书籍 → 提及进度
- 有时间胶囊（7/30/365 天前记录）→ 温暖回顾
- 有天气数据 → 自然融入

---

### 4. 每日 Top 3 设定

**触发方式**：早报引导后，用户回复今天最重要的 3 件事

**示例对话**：

```
【用户】
1. 完成需求文档
2. 和产品讨论方案
3. 下班前写日报

【AI】
✅ 收到！今天的 Top 3：
1️⃣ 完成需求文档
2️⃣ 和产品讨论方案
3️⃣ 下班前写日报
加油~
```

**晚间复盘**：晚上 21:00 打卡时会问"今天的 Top 3 完成得怎么样？"

---

### 5. 习惯干预系统（微实验）

**触发方式**：

- AI 主动提议：周一早报中（如果发现行为模式）
- 用户主动：说"帮我设计一个微实验"

**实验设计**：

```
【AI 提议】
💡 发现你最近总是睡前刷手机导致失眠...
要不要试个小实验？

假设：睡前 15 分钟放下手机 → 改善睡眠质量
触发词：手机、刷、睡前
微行动：放下手机，做 5 分钟深呼吸
时长：7 天

试试看吗？
```

**实验触发**：

- 用户消息匹配触发词 → AI 轻轻提醒"要不要试试那个微行动？"
- 不会频繁打扰（每天最多 1-2 次）

**实验结束**：

- 自动结束：7 天后总结
- 手动结束：用户说"结束实验"

---

### 6. 决策追踪（Decision Track）

**触发方式**：AI 识别"决策时刻"

**识别关键词**：

- 要不要、纠结、犹豫、决定了、算了不 xxx 了

**流程**：

```
【用户】
纠结要不要跳槽...算了还是先干着吧

【AI】
记住啦，你决定暂时不跳槽了
3 天后我们回顾一下这个决定怎么样？

【3 天后早报中】
前几天你纠结跳槽的事，最后决定先不动 — 现在回头看怎么样？

【用户回复结果】
还好，这几天心态稳定了很多

【AI】
✅ 决策复盘已记录，看来是个对的选择~
```

## 六、深度分析功能

### 1. 主题深潜（Deep Dive）

**触发方式**：

- 触发词："回顾/分析/梳理/深潜/盘点" + 话题

**示例对话**：

```
【用户】
帮我回顾一下最近的情绪变化

【AI】
🔍 正在搜索全历史数据，深度分析中...

【几秒后】
📊 深潜报告：情绪变化

**时间线**：
02-15 💭 "今天特别焦虑" — 焦虑
02-18 🌤️ "和朋友聊天后好多了" — 平静
02-22 😊 "项目上线了超开心" — 愉悦
...

**趋势**：整体从焦虑期逐渐回升到稳定期

**关键洞察**：
1. 社交互动是你情绪修复的重要方式
2. 工作成就感明显提升情绪
3. 焦虑期多集中在项目关键节点

**建议**：项目冲刺期保持适度社交，能帮你缓冲压力
```

**保存选项**：用户说"保存下来" → 生成 md 文件

---

### 2. 对话式任务（Agent Loop）

**触发方式**：用户询问笔记中的内容

**示例对话**：

```
【用户】
我之前写过什么关于小明的？

【AI 内部流程】
1. internal.search 搜索关键词"小明"
2. 找到 5 条记录
3. 汇总回复

【AI 回复】
找到 5 条关于小明的记录：
- 02-10：一起吃饭聊了很久
- 02-15：小明推荐了一本书
- 02-20：和小明吐槽工作
...

要详细看哪一条吗？
```

**支持操作**：

- `internal.search`：搜索关键词
- `internal.read`：读取指定文件
- `internal.list`：列出目录文件

## 七、用户设置功能

### 1. 修改昵称（settings.nickname）

**触发词**：叫我 XX、我叫 XX、我的名字是 XX

**反馈**：

```
好的，以后叫你小天~
```

---

### 2. 给 AI 起名（settings.ai_name）

**触发词**：我叫你 XX、叫你 XX、你叫 XX

**注意区分方向**：

- "我叫小天"（用户自己）→ `settings.nickname`
- "我叫你健健"（给 AI 起名）→ `settings.ai_name`

**反馈**：

```
好呀，以后我就叫「健健」啦~
```

---

### 3. 修改说话风格（settings.soul）

**触发词**：

| 操作 | 触发词 | 示例 |
|------|--------|------|
| 覆盖风格 | 说话XX一点、正式一些 | "说话正式一些" |
| 追加风格 | 再XX一点 | "再幽默一点" |
| 恢复默认 | 恢复默认风格 | "回到原来的说话方式" |

**反馈**：

```
收到，我会试着更正式一些~
```

---

### 4. 记录个人信息（settings.info）

**触发词**：我是做 XX 的、我在 XX（城市）、我养了 XX

**分类**：

- `city`：城市
- `pets`：宠物
- `people`：人际关系
- `other`：其他

**反馈**：

```
记住啦，你在深圳工作~
```

---

### 5. 功能管理（settings.skills）

**触发词**：

| 操作 | 触发词 | 反馈 |
|------|--------|------|

## 总结：功能触发与反馈模式

### 触发方式分类

| 触发类型 | 功能 | 反馈特点 |
|---------|------|---------|
| **自动触发** | 速记保存、分类归档、读书/影视识别 | 无声保存或简短确认 |
| **定时触发** | 早报、打卡、深度自问、日报、情绪日记、周报 | 主动推送，温暖引导 |
| **关键词触发** | 待办管理、设置修改、数据导出/销毁 | 精准识别，快速反馈 |
| **自然语言** | 所有功能均支持自然表达（不需要记忆指令） | AI 智能理解意图 |

### 反馈形式分类

| 反馈类型 | 适用功能 | 特点 |
|---------|---------|------|
| **简短确认** | 速记、待办、归档 | 1-2 句话，不打扰 |
| **温暖对话** | 打卡、深度自问、习惯干预 | 像朋友聊天，不生硬 |
| **结构化展示** | 待办列表、周报、月报、深潜报告 | 清晰易读，数据可视化 |
| **多段回复** | 数据导出、周报、深潜、财务月报 | 先发确认消息，再发结果 |
| **二次确认** | 数据销毁、重要决策 | 安全机制，防止误操作 |

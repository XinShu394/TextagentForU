## 🔄 恢复指南

如果日后要继续使用企业微信方案：

### 1. 检查服务状态

```bash
ssh root@<REDACTED_SERVER_IP>
systemctl status textagent
curl http://127.0.0.1:9000/health
```

### 2. Cloudflare Tunnel 配置（如 NS 已生效）

```bash
# 登录 Cloudflare
cloudflared tunnel login

# 创建隧道
cloudflared tunnel create textagent

# 配置隧道（创建 ~/.cloudflared/config.yml）
tunnel: <TUNNEL_ID>
credentials-file: /root/.cloudflared/<TUNNEL_ID>.json
ingress:
  - hostname: textagent.cn
    service: http://localhost:9000
  - service: http_status:404

# 添加 DNS 路由
cloudflared tunnel route dns textagent textagent.cn

# 启动隧道
cloudflared tunnel run textagent
```

### 3. 企微回调配置

- URL: `https://textagent.cn/wework`
- Token: 与 .env 中 WEWORK_TOKEN 一致
- EncodingAESKey: 与 .env 中 WEWORK_ENCODING_AES_KEY 一致

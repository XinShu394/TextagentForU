## 服务器侧影响

### 当前服务器状态

服务器实际部署路径为 `/opt/textagent/`（见 [云端部署实操记录](云端部署实操记录.md)），**不受此次修改影响**。

### 如果使用 deploy_textagent.sh 全新部署

修改后的部署脚本会将代码 clone 到 `/root/TextagentForU/`，systemd 服务也指向该目录。

### 服务器更新建议

由于服务器已有 `/opt/textagent/` 部署，建议使用以下方式更新：

```bash
cd /opt/textagent && git pull origin main && sudo systemctl restart textagent
```

如果服务器上 git remote 还指向旧地址，需要先修正：

```bash
cd /opt/textagent
git remote set-url origin https://github.com/XinShu394/TextagentForU.git
git pull origin main
sudo systemctl restart textagent
```

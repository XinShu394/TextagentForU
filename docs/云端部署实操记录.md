## 三、常用操作命令

### 3.1 更新代码并重启

```bash
cd /opt/karvis && git pull origin main && pkill -f "python.*app.py" && cd src && nohup python app.py > ../karvis.log 2>&1 &
```

### 3.2 查看运行状态

```bash
ps aux | grep app.py
```

### 3.3 查看实时日志

```bash
tail -f /opt/karvis/karvis.log
```

### 3.4 查看最近日志（最后100行）

```bash
tail -100 /opt/karvis/karvis.log
```

### 3.5 仅重启（不更新代码）

```bash
pkill -f "python.*app.py" && cd /opt/karvis/src && nohup python app.py > ../karvis.log 2>&1 &
```

### 3.6 查找项目位置（如果忘记了）

```bash
find / -name "app.py" -path "*/karvis/*" 2>/dev/null
```

## 五、常见问题

### Q1: `cd: /root/karvis: No such file or directory`

**原因**: 项目安装在 `/opt/karvis/`，不是 `/root/karvis/`

**解决**: 使用正确路径 `cd /opt/karvis`

### Q2: 更新后服务没启动

**检查**:
```bash
ps aux | grep app.py
```

**手动启动**:
```bash
cd /opt/karvis/src && nohup python app.py > ../karvis.log 2>&1 &
```

### Q3: 查看错误日志

```bash
tail -50 /opt/karvis/karvis.log | grep -i error
```

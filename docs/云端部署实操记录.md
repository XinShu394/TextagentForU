## 三、常用操作命令

> ⚠️ **同一台服务器上有两套部署，路径和管理方式完全不同，切勿混淆！**

### 两套部署速查对照

| | TextAgent（个人版） | TextAgentForU（多用户版） |
|---|---|---|
| **项目路径** | `/opt/textagent/` | `/root/TextAgentForU/` |
| **源码目录** | `/opt/textagent/src/` | `/root/TextAgentForU/src/` |
| **进程管理** | **systemctl**（systemd 服务） | **nohup**（直接进程） |
| **端口** | 9001 | 9000 |
| **GitHub 仓库** | — | `XinShu394/TextagentForU.git` |
| **远程同步** | `cd /opt/textagent && git pull origin main && sudo systemctl restart textagent` | 👇 见下方 3.1 |

### 3.1 ⭐ TextAgentForU 更新代码并重启（最常用）

```bash
cd /root/TextAgentForU && git pull origin main && kill $(pgrep -f "python3 app.py"); sleep 1; cd /root/TextAgentForU/src && nohup python3 app.py > /root/textagent.log 2>&1 &
```

**拆解说明**：

| 步骤 | 命令 | 作用 |
|------|------|------|
| 1 | `cd /root/TextAgentForU` | 进入项目根目录 |
| 2 | `git pull origin main` | 从 GitHub 拉取最新代码 |
| 3 | `kill $(pgrep -f "python3 app.py")` | 杀掉旧进程 |
| 4 | `sleep 1` | 等待端口释放 |
| 5 | `cd /root/TextAgentForU/src` | 进入源码目录 |
| 6 | `nohup python3 app.py > /root/textagent.log 2>&1 &` | 后台启动新进程 |

> ⚠️ **注意**：路径 `/root/TextAgentForU` 中 A 和 F 是**大写**，GitHub 仓库名 `TextagentForU` 中 a 是小写。这是 Linux 大小写敏感的，**不能写成 `/root/TextagentForU`**。

### 3.2 TextAgent（个人版）更新代码并重启

```bash
cd /opt/textagent && git pull origin main && sudo systemctl restart textagent
```

## 四、Systemd 服务配置

服务配置文件位置：`/etc/systemd/system/textagent.service`

```ini
[Unit]
Description=TextAgent AI Assistant
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/textagent/src
ExecStart=/opt/textagent/src/venv/bin/python app.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

> ⚠️ `ExecStart` 使用 **venv 内的 python**（`/opt/textagent/src/venv/bin/python`），不是系统 python3

### 常用 systemctl 命令

| 命令 | 说明 |
|------|------|
| `sudo systemctl start textagent` | 启动服务 |
| `sudo systemctl stop textagent` | 停止服务 |
| `sudo systemctl restart textagent` | 重启服务 |
| `sudo systemctl status textagent` | 查看状态 |
| `sudo systemctl enable textagent` | 开机自启 |
| `journalctl -u textagent -f` | 实时日志 |

### 修改配置后需要重新加载

```bash
sudo systemctl daemon-reload
sudo systemctl restart textagent
```

### 一键修复 systemd 配置（如果被覆盖）

```bash
sudo tee /etc/systemd/system/textagent.service << 'EOF'
[Unit]
Description=TextAgent AI Assistant
After=network.target

sudo systemctl daemon-reload
```

## 六、常见问题

### Q1: `cd: /root/textagent: No such file or directory`

**原因**: 项目安装在 `/opt/textagent/`，不是 `/root/textagent/`

**解决**: 使用正确路径 `cd /opt/textagent`

### Q2: `nohup: failed to run command 'python': No such file or directory`

**原因**: 服务器上没有裸 `python` 命令

**解决**: 使用 venv Python 或系统 `python3`

```bash
# venv Python（推荐）
/opt/textagent/src/venv/bin/python

# 系统 Python3
/usr/bin/python3
```

### Q3: `ModuleNotFoundError: No module named 'flask'`

**原因**: 使用了系统 Python3 而不是 venv，导致找不到已安装的依赖

**解决方案 A（推荐）**: 修改 systemd 使用 venv Python
```bash
# ExecStart 改为:
ExecStart=/opt/textagent/src/venv/bin/python app.py
```

**解决方案 B**: 用 venv 重新安装依赖
```bash
cd /opt/textagent/src && source venv/bin/activate && pip install -r requirements.txt && deactivate
```

**解决方案 C**: 用系统 Python3 安装依赖
```bash
pip3 install -r /opt/textagent/src/requirements.txt
```

### Q4: systemd 服务启动失败 `code=exited, status=1/FAILURE`

**可能原因**:
1. `ExecStart` 路径错误（比如指向了不存在的 venv）
2. `WorkingDirectory` 路径错误

**排查**:
```bash
# 查看服务状态
sudo systemctl status textagent

# 查看详细日志
journalctl -u textagent --no-pager | tail -50
```

**修复**:
```bash
# 查看当前配置
cat /etc/systemd/system/textagent.service

# 修改配置
sudo nano /etc/systemd/system/textagent.service

# 确保 ExecStart 使用正确的 python3 路径
# ExecStart=/usr/bin/python3 app.py

# 重新加载并重启
sudo systemctl daemon-reload
sudo systemctl restart textagent
```

### Q4: 更新后服务没启动

**检查**:
```bash
sudo systemctl status textagent
```

**手动启动**:
```bash
sudo systemctl start textagent
```

### Q5: 查看错误日志

```bash
journalctl -u textagent --no-pager | grep -i error | tail -20
```

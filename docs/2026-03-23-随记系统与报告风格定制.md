# 2026-03-23 随记系统 & 报告风格定制

## 变更概述

本次新增两项功能：

1. **随记系统（Memo）**：用户发送"记 + 内容"即可主动保存随记，AI 自动提取标签，按日期+标签存储，支持查看和搜索。
2. **报告风格定制（Report Style）**：用户可通过对话自定义日报/周报/月报的输出风格（如"简洁列表式"、"注重情感陪伴"），统一 `report_style` 字段控制所有报告。

## 需求背景

### 随记系统
- 现有 Quick-Notes 是**被动**自动记录，用户缺少一个明确的"我要记这个"的主动入口
- 用户看书、灵感闪现时，希望快速发一条消息就能记录，并支持标签分类和后续检索
- 与 Quick-Notes 互不干扰，独立存储在 `02-Notes/随记/` 目录

### 报告风格定制
- 不同职业/偏好的用户对日报周报的输出风格需求不同
- 有人喜欢简洁列表，有人注重情感陪伴，有人偏数据导向
- 现有 `soul_override` 是全局说话风格，不能单独控制报告输出

## 技术设计

### 随记触发词
- 单字"**记**"即可触发（如"记 今天看到一段话很有启发"）
- 用户也可手动指定标签："记 #读书 人类简史里的认知革命很有意思"

### 标签提取
- 优先识别用户手动写的 `#tag`
- 未手动指定时，调用 Flash 模型（Qwen）自动提取 1-3 个标签
- 降级：Flash 失败时保存为无标签

### 存储格式
```
02-Notes/随记/2026-03-23.md
```

条目格式：
```markdown
### 14:30 #读书 #灵感
看到《人类简史》里提到认知革命，突然想到...
*— 2026-03-23 14:30*

---
```

### 报告风格注入
- `user_config.json` 新增 `report_style` 字段（默认空串）
- 空值：日报保持纯规则生成（零成本），周报/月报保持原有 prompt
- 非空：日报升级为 AI 生成，周报/月报 prompt 末尾追加风格偏好

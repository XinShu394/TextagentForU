# 待办时间反馈确认功能

**更新日期**: 2026-04-01  
**版本**: V15

---

## 一、问题背景

### 1.1 用户反馈

用户设置待办提醒（如"明早九点四十提醒我去上班"），系统回复"已帮你设置好提醒"，但第二天却没有收到提醒。

### 1.2 问题分析

从用户截图来看，存在以下问题：

1. **时间识别不确定**：LLM 可能将"明早九点四十"解析为只有 `HH:MM` 格式而缺少日期
2. **缺乏明确反馈**：系统回复没有告诉用户具体记录的日期和时间，用户无法确认待办是否被正确理解
3. **沉默失败**：如果时间解析错误，用户只能在第二天发现没收到提醒时才知道出了问题

---

## 二、改进方案

### 2.1 核心改进：明确时间反馈

在用户添加待办成功后，系统会返回明确的日期和时间反馈，格式如下：

| 待办类型 | 反馈示例 |
|---------|---------|
| 一次性提醒 | `已记下 2026-04-01 09h40m 提醒你「去上班」` |
| 循环提醒 | `已记下每天 09:40 提醒你「吃药」` |
| 带截止日期 | `已记下待办「交报告」，截止 2026-04-05` |
| 普通待办 | `已记下待办「买猫粮」` |

**关键点**：
- 一次性提醒必须显示完整的 `YYYY-MM-DD HHhMMm` 格式
- 用户可以立即确认日期是否正确（是今天还是明天？是上午还是下午？）
- 如有问题，用户可以及时修改

### 2.2 格式强化

更新 `FLASH_QUICK_PROMPT` 中的提示，强调一次性提醒必须使用完整日期格式：

```
⚠️ 一次性提醒的 remind_at 必须是完整 "YYYY-MM-DD HH:MM" 格式（如 "2026-04-01 09:40"），只有循环待办才用 "HH:MM"
```

## 三、技术实现

### 3.1 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/skills/todo_manage.py` | `add()` 函数返回明确的时间反馈 |
| `src/prompts.py` | `FLASH_QUICK_PROMPT` 强化格式要求 |

### 3.2 代码逻辑

```python
# todo_manage.py add() 函数新增逻辑

if remind_at:
    if len(remind_at) > 5:
        # 一次性提醒：YYYY-MM-DD HH:MM → 显示完整时间
        date_part, time_part = remind_at.split(" ")
        time_display = time_part.replace(":", "h") + "m"
        feedback = f"已记下 {date_part} {time_display} 提醒你「{content}」"
    else:
        # 循环提醒：只有 HH:MM
        recur_text = _recur_display(todo)
        feedback = f"已记下{recur_text}提醒你「{content}」"
```

## 四、防护层级

待办提醒系统现在有三层保护：

| 层级 | 机制 | 说明 |
|------|------|------|
| 1. Prompt 规则 | 强调完整日期格式 | LLM 解析时优先使用正确格式 |
| 2. 兜底补全 | `todo.add` 自动补全日期 | 即使 LLM 只返回 `HH:MM`，也会自动补全为 `YYYY-MM-DD HH:MM` |
| 3. 明确反馈 | 返回完整时间给用户 | 用户可确认时间是否正确，有问题可及时修改 |
